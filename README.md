# Phân tích Dữ liệu Thương mại điện tử & Chân dung Khách hàng (Power BI)

##  Tổng quan Dự án (Project Overview)
Dự án này sử dụng dữ liệu giả định của một nền tảng Thương mại điện tử (gồm ~138.000 đơn hàng và 25.000 khách hàng) để phân tích hiệu suất kinh doanh, thấu hiểu chân dung người tiêu dùng và đánh giá hiệu quả của các kênh bán hàng. 

**Công cụ sử dụng:** 
* Data Cleaning & Transformation: Power Query
* Data Modeling: Power BI (Star Schema)
* Data Visualization: Power BI
* Báo cáo phân tích: PDF Report

##  Cấu trúc Kho lưu trữ (Repository Structure)
* `Bao_cao_Phan_tich_Khach_hang.pdf`: File báo cáo chi tiết phân tích Insight (Business Analyst Report).
* `Ecommerce_Dashboard.pbix`: File gốc Power BI chứa Data Model và Visualizations.
* `Data/`: Chứa các file dataset gốc dạng `.csv`.

##  Các Insights Nổi Bật (Key Findings)
1. **Chân dung Khách hàng:** Nhóm khách hàng Trung niên (trên 45 tuổi) chiếm thế áp đảo với hơn 51% tổng doanh thu. Tỷ lệ nam/nữ cân bằng.
2. **Hành vi Mua sắm:** Kênh Mobile App dẫn đầu với hơn 40% số lượng đơn hàng, cho thấy thói quen mua sắm dịch chuyển mạnh lên thiết bị di động.
3. **Phân khúc B2B:** Top 10 khách hàng chi tiêu nhiều nhất chủ yếu thuộc nhóm Doanh nghiệp (Business), mang lại nguồn thu ổn định và giá trị đơn hàng lớn.

##  Hướng dẫn xem dự án
Vui lòng xem file **PDF Report** đính kèm để đọc chi tiết các phân tích và đề xuất chiến lược nghiệp vụ (Business Strategies).
